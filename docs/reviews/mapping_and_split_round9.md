## Purpose

Round9 checks whether the Round8 literature-supported exact pairs are new training labels, already-existing positives, or unsafe candidates that would leak into holdout/challenge evaluation.

This round also verifies substrate/product structure mapping against PubChem where possible and keeps conditional negative candidates separate from biological global negatives.

## Main Result

The four Round8 exact-positive candidates are **not new positive labels**. All four already exist in `outputs/modular/ltr/reactions.parquet` as `gold` and `is_clean=true`.

However, all four have zero hits in:

- `outputs/modular/ltr/clean_candidates_full.parquet`
- `outputs/modular/ltr/clean_candidates.parquet`

This changes the diagnosis:

> The immediate production blocker is not only missing positive labels. It is candidate-generation recall and source-traceable rule coverage. The system already has some gold positives that the deployment-faithful clean generator fails to enumerate.

## Chemical Mapping

`chemical_mapping_round9.csv` contains eight compound-level mapping rows.

Status counts:

- `confirmed_by_local_and_pubchem_block1`: 7
- `needs_manual_structure_review`: 1

The one flagged structure is `2'-fucosyllactose`. The local reaction table maps the substrate to InChIKey block `SNFSYLYCDAVZGP`, while the PubChem name query returned block `HWHQUWQCBPAQQH`. This is most likely a representation/name-specific issue around 2'-FL stereochemistry or reducing-end form, but it must not be silently normalized without manual review.

## Split And Holdout Risk

`urolithin C -> urolithin A` overlaps the production challenge panel by name and should remain held out until the challenge/holdout policy is explicit.

The other three pairs are existing gold positives with scaffold fold assignments in `pairs.parquet`, but their absence from clean candidate generation means they should be used to debug candidate recall, not as duplicate positive imports.

## Negative Label Review

Round8's two negative candidates remain conditional only:

- alpha1,2-fucosyl non-activity is enzyme/context-specific, not a global negative for 2'-FL.
- rosmarinic-acid stability in a defined context is not a global negative for caffeic acid -> dihydrocaffeic acid.

Both remain `training_allowed_round9=false`.

## Production Implication

Ray's concern about small sample claims remains valid, but Round9 sharpens the failure mode:

1. High metrics are unsupported because some evaluations use only `n_pts=10`.
2. Reaction family coverage is incomplete.
3. More importantly, some known gold reactions are not generated by the production-faithful clean candidate pipeline.
4. Therefore the model cannot be production-ready even before judging the LTR ranker, because the ranker cannot score a true product that never enters the candidate set.

## Round10 Direction

Round10 should focus on evidence-based rule and sample acquisition:

1. Compare current reaction-family gaps against ECREACT, RetroRules, gapseq, gutSMASH, Rhea, PubMed, and curated local positives.
2. Prioritize reaction families that are important for food-gut metabolism and currently missed by generation.
3. Recover or import only source-traceable rules with database or literature provenance.
4. Build positive CSV rows only from exact substrate-product evidence.
5. Build negative CSV rows only from explicit assay non-conversion, context-constrained organism/genome evidence, or hard decoys clearly marked as ranking negatives.
6. Rerun generation recall before retraining.
