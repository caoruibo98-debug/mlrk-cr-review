## What This Means

Ray's earlier concern that the model was being judged on too-small or wrong panels was correct. Round11 adds a stronger diagnosis:

1. The data has enough existing gold examples to reveal real generator failures.
2. The clean generator currently uses a narrower/sampled rule set than the full master/recovered rule space.
3. Several production-critical gut-food reactions are therefore absent before ranking.
4. Production readiness cannot be fixed by retraining alone.

## Round12 Direction

Round12 should create a source-traceable generator rule import layer:

1. Start from `known_gold_generator_trace_round11.csv`.
2. For each known-gold miss, select the recovered rule with the strongest source provenance.
3. Gate each rule by source reaction, license, direction, and exact-pair support.
4. Add the approved rule to a deployment generator overlay, not as a new label.
5. Rerun clean candidate generation on the four known-gold pairs.
6. Require `clean_candidates_full` to contain the true product before any retraining.
