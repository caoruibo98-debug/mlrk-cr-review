# Reaction Type Production Audit Round 4

## Working conclusion

Ray's judgment is mostly correct: the production blocker is not simply "too few rows".
It is insufficient evidence-backed reaction-family coverage after the model route:

```text
raw positive pool -> reactions.parquet -> rule generation -> clean_candidates_full.parquet
```

The current system can enumerate and rank some candidates, but many food-gut
reaction families either cannot be generated by the clean rule pool or are
available only in the full rule audit, not in the local positive-pool rule set.
That blocks a defensible production claim.

## External model comparison

The current public landscape supports a conservative rule:

```text
Do not invent positive reactions from plausible chemistry.
Use public databases and papers to create labels; use rules only to generate candidates.
```

Evidence-backed external references:

- ECREACT / `rxn4chemistry/biocatalysis-model` uses Rhea, BRENDA, PathBank, and MetaNetX reactions with EC labels and covers all 7 EC classes.
- RetroRules 2026 contains 1,174,216 templates from 92,698 source reactions, integrating MetaNetX, Rhea, USPTO, and UniProt support. It is a rule/template source, not a gut occurrence label source.
- RetroPathRL expects explicit `Rule_ID`, `Reaction_ID`, `Rule_SMARTS`, and EC fields, which is a good provenance schema for our rule manifest.
- gapseq integrates MNXref, MetaCyc, ModelSEED, KEGG, BRENDA, UniProt, TCDB, and BiGG for bacterial pathway/model reconstruction.
- gutSMASH focuses on anaerobic gut metabolic gene clusters and supports gene/pathway plausibility, not exact substrate-product labels by itself.
- GutBug reports training on 3,457 enzyme substrates and a curated database of 363,872 enzymes from about 700 gut bacterial strains, predicting EC/reaction centers; this is useful as an external coverage benchmark but not a direct positive-label import unless the underlying reaction evidence is recoverable.
- MDM-Pred collected more than 600 compounds from over 80 publications, with 329 known HGM-metabolized compounds; useful as a drug-like external challenge set, not as the core food-derived training set.
- MIMOSA/MIMOSA2/Mangosteen-like tools model metabolite generation/depletion from microbiome profiles or reference networks; useful for conditional/unlabeled logic, not exact chemical negatives.

- `substrate_smiles`
- `substrate_inchikey`
- `product_name_en`
- `product_name_zh`
- `product_smiles`
- `product_inchikey`
- `reaction_family`
- `reaction_category`
- `reaction_type`
- `macro_module`
- `source_type`
- `source_id`
- `pmid_or_doi`
- `database_reaction_id`
- `enzyme_name`
- `enzyme_ec`
- `microbe_or_strain`
- `evidence_level`
- `rule_smarts`
- `rule_source_id`
- `training_allowed`
- `holdout_guard`

Allowed positive evidence:

1. Direct literature reaction: exact substrate and exact product observed in a gut microbe, gut consortium, fecal fermentation, strain assay, purified enzyme from gut microbe, or highly relevant anaerobic gut system.
2. Curated biochemical database reaction: Rhea, BRENDA, MetaNetX, PathBank, VMH, KEGG/BioCyc-derived source with exact compound mapping and EC/provenance.
3. Existing high-evidence local row that survives canonicalization and route trace.

Not allowed as positive evidence:

- Rule-generated product without a cited source reaction.
- Similar reaction on a related molecule without exact substrate/product verification.
- Model-predicted EC/reaction center without product-level verification.
- A plausible gut reaction that has no literature or curated database support.

## Negative sample policy

Do not use "not found in database" as a true negative.

Recommended label types:

- `positive`: exact evidence-backed substrate-product reaction.
- `hard_decoy`: same substrate, rule-generated product, not a known positive for that substrate in the curated pool. This is usable for ranking contrast, but not a biological false claim.
- `conditional_negative`: organism/context-specific absence supported by genome-scale model, missing enzyme/gene, or defined microbiome profile. This must include organism/model/context fields.
- `assay_negative`: paper reports no conversion under defined assay conditions. Strongest negative, but rare.
- `unlabeled`: unknown. Default for everything else.

Training can use `hard_decoy` as ranking negatives, but evaluation and production claims must not call them experimentally false.

## Claim boundary

Current defensible claim:

> The system is a hybrid evidence-backed candidate generator and ranking prototype for food-gut microbial biotransformation. It has internal rule-generation and ranking evidence, but it is not yet production-ready because key food-gut reaction families lack verified positive coverage and many verified reactions are not generated by the deployed clean rule pool.

Current non-defensible claim:

> The model can generally predict real gut microbial metabolism of food compounds.

That claim requires external validation or strong independent evidence.
